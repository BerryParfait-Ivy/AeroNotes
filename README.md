# AeroNotes
AeroNotes is a note-taking web app in the glossy Frutiger Aero style, built from a Figma design with plain HTML, CSS and JavaScript. You can draw and write notes on a canvas with tools like a pen, marker, highlighter and eraser, then organize them into folders. Still being polished owo
